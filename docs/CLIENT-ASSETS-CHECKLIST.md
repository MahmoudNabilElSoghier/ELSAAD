# قائمة الأصول المطلوبة من العميل — السعد للدراجات النارية

## أولويات عالية (blocking) — نحتاجها قبل الإطلاق
- [ ] اللوجو بصيغة SVG أو PNG بخلفية شفافة (أعلى جودة متاحة)
- [ ] رقم الموبايل الرسمي (الخط الساخن)
- [ ] رقم الواتساب الرسمي بصيغة دولية (مثال: 201234567890)
- [ ] الإيميل الرسمي
- [ ] عناوين الفروع الكاملة + أرقام تليفون كل فرع
- [ ] ساعات العمل (رسمية)
- [ ] أسماء صفحات السوشيال ميديا (Facebook, Instagram, YouTube, TikTok)

## أولويات متوسطة — للتحسين قبل الإطلاق
- [ ] 8-12 صورة للمعرض من الداخل والخارج
- [ ] 5-8 صور للموديلات (بجودة عالية)
- [ ] صور الفريق / الفنيين (اختياري)
- [ ] لوجوهات الماركات اللي بيتم توزيعها رسمياً
- [ ] نصوص "من إحنا" (٣-٤ سطور بالعربي)
- [ ] سنة التأسيس + عدد الفروع الفعلي

## أولويات منخفضة — لاحقاً
- [ ] فيديو قصير (15-30 ثانية) للـ Hero
- [ ] شهادات عملاء حقيقية (٣ شهادات)
- [ ] شعار إعلاني (tagline)

## ملاحظات
- أي صورة مرفوضة من ناحية الحقوق، نستبدلها فوراً.
- الأرقام في الموقع حالياً هي placeholders — مش أرقام حقيقية.
- لو الأصول متأخرة، الإطلاق ممكن يمشي بالـ placeholders، ونستبدلها في تحديث.
